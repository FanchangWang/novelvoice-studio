# v0.5.0 AI 生产链重构：产品重定向与设计

- 日期：2026-11-26
- 基线版本：0.4.0
- 基线提交：`fa77fd6`
- 状态：方向已确认，P1 数据层已实施，生产链与 UI 待实施
- 关联文档：[数据模型与迁移设计](V0_5_0_DATA_MODEL_MIGRATION_2026-11-26.md)

> 本文件定义 0.5.0 的产品口径与实施边界。它不覆盖旧需求、旧验收单和阶段报告；
> 旧文档保留历史结论，涉及 0.5.0 的冲突以本文件为准。

---

## 1. 结论

本轮阶段 0–3 轻度验收中止，不计为通过。验收暴露的不是零散 bug，而是主链设计偏差：

| 问题 | 现状 | 根因 | 影响 |
|---|---|---|---|
| UI 可读性 | 9–10px 元信息大量使用 `#626b78` / `#4b535f`；对比度仅 3.65:1 / 2.53:1 | 缺少颜色、字号与可读性验收规范 | 深色主题下无法阅读 |
| 空项目 | 只能创建书目，不能导入正文或创建章节 | “项目”概念先于编辑能力落地 | 新建后无路可走 |
| 全书角色 | 逐章增量注册表，角色性格由章节片段拼接 | 未实现需求中的“全书角色提取” | 人物弧、伏笔、倒叙、成长变化丢失 |
| 角色状态 | `characters.age_range` 是一个静态值 | 没有场景级状态快照 | 幼年/青年/老年、紧张/害怕等无法表达 |
| 有声化改编 | `segments.speech_text` 直接复制原文 | 没有独立的改编层 | 阅读性提示、动作和声音没有转为有声格式 |
| 配音员 | `VoiceProfile` 绑定书内 owner | 没有全局配音员库与选角表 | 不能跨书复用，每个角色重复设计 |
| 人工审核 | 每个角色、片段都要人确认 | 审核被设计成主流程而不是例外 | AI 没有减轻工作，反而增加工作量 |

以下能力继续有效，不在 0.5.0 重做：

- TXT 导入、编码识别、章节解析、章节重命名/拆分/合并。
- Qwen3-TTS VoiceDesign + CosyVoice3 的引擎服务、去齿链路、WAV 版本与回退。
- 原文只读、音频不存 SQLite、回环地址、无云 AI、无遥测等安全边界。
- 阶段 3 的音质结论与遗留问题；0.5.0 不重新评审音质。

## 2. 已确认决策

| 决策 | 结论 |
|---|---|
| 路线 | 暂停原阶段 4，先做 0.5.0「AI 生产链重构」 |
| 音效/环境音 | 0.5.0 只做剧本标记（cue），不做实际混音 |
| 空项目 | 移除“新建空项目”入口；新建书只能通过导入 TXT |
| 已有空项目 | 在工作区提供“导入正文到本书”或“删除空项目” |
| 默认改编强度 | **轻改编**；标准/强改编作为可选档 |
| 版本 | 0.5.0 是主链重构，不是 0.4.x 补丁 |
| 原阶段 4/5 | 顺延为 0.6.0（队列/播放器）与 0.7.0（M4B 导出） |

## 3. 目标与非目标

### 3.1 目标

1. **AI 先给出完整制作方案，人只处理异常。** 高置信结果默认通过；低置信、冲突、缺音色、改编风险进入异常收件箱。
2. **先理解全书，再分析章节。** 生成角色圣经、人物弧、关系、剧情时间线，再逐章分场并记录角色状态。
3. **原文与改编分离。** 原文只读；有声剧本单独版本化、可对照、可回退。
4. **配音员全局化。** 配音员可跨书复用；新书自动选角，历史没有合适声音时自动生成并绑定。
5. **UI 可读、可扫读。** 对比度、字号、层级和状态色达到可验收标准，不再依赖 9–10px 灰字。
6. **保留现有音频链路。** Qwen + CosyVoice、单段生成、WAV 版本与回退继续使用。

### 3.2 非目标

- 0.5.0 不做实际音效素材检索、环境音混音、BGM 编排；只输出 cue 和时间点。
- 0.5.0 不做持久化批量队列、连续播放器、M4B 导出；这些属于 0.6.0/0.7.0。
- 不做在线账号、云同步、付费云模型、遥测。
- 不做用户声音克隆训练或模型微调。
- 不做手写章节编辑器；原创写作是独立产品链路，后续单独评估。
- 不重新评审音质、sad 表现力、句尾气声；不宣称许可证已完成。

## 4. 新的端到端流程

```text
导入 TXT（唯一新建路径）
  → 全书粗读 / 角色圣经
  → 逐章分场 / 角色状态快照
  → 有声剧本（默认轻改编）
  → 自动选角（全局配音员库）
  → 制作方案（只审异常，一次确认）
  → 选中片段同步生成（0.5.0）
  → 批量队列 / 连续播放（0.6.0）
  → M4B 导出（0.7.0）
```

### 4.1 导入

- 书库只保留“导入 TXT”作为新建入口。
- 已有空书进入工作区时，空状态提供“导入正文到本书”和“删除空项目”。
- 导入预览、编码确认、章节解析、重复检测保持现有行为。
- 导入完成后直接进入“设定集”，不再要求用户先逐个确认角色。

### 4.2 全书角色圣经

- 系统按章节/窗口粗读，提取人物、别名、身份、关系、关键事件。
- 通过确定性合并 + LLM 归并，生成全书角色表与人物弧。
- 记录剧情时间线：`story_time` 与章节顺序分离，支持倒叙、插叙、伏笔、回忆。
- 角色可标注 `role_tier`（主角/重要配角/次要角色/路人）。
- 角色弧可包含多个阶段：幼年、少年、青年、中年、老年；每个阶段有章节/剧情时间范围、性格与声音倾向。
- 低置信别名冲突、疑似同一人物、身份反转进入异常收件箱。

### 4.3 逐章分场与角色状态

- 每章拆为场景（scene），记录地点、时间、视角、气氛和原文范围。
- 每个场景维护出场角色状态快照：
  - 年龄阶段；
  - 身体状态（受伤、疲惫、醉酒等）；
  - 心理/情绪状态（紧张、害怕、压抑、张扬等）；
  - 关系状态（陌生、信任、敌对、隐瞒等）；
  - 知情状态（知道什么、不知道什么、误以为什么）；
  - 伪装/身份状态（易容、假名、卧底等）；
  - 声音提示（沙哑、虚弱、刻意压低等）。
- 状态按剧情时间取，不按章节号取；倒叙章节不能把“老年状态”带进“青年场景”。
- 说话人归属、情绪、演绎方式仍保留置信度与证据。

### 4.4 有声剧本

- 新增独立“有声剧本”版本层，原文不被改写。
- 每个剧本单元（unit）至少支持：

| 类型 | 用途 | 是否进入 TTS |
|---|---|---|
| `narration` | 旁白叙述 | 是 |
| `dialogue` | 角色对白 | 是 |
| `inner_monologue` | 内心独白 | 是 |
| `sfx` | 音效 cue，例如惊堂木重拍（啪） | 否 |
| `ambience` | 环境音 cue，例如雨声、马蹄声 | 否 |
| `pause` | 停顿/节奏标记 | 否 |

- 默认 **轻改编**：尽量保留原文措辞，只做有声化必需的处理：
  - 去掉“他说/她道/问道”等纯阅读提示；
  - 把拟声词与动作声拆成 `sfx` cue；
  - 长句按呼吸和语义切分；
  - 保留原文的叙述顺序、事实和人物关系。
- 标准/强改编作为可选档，必须显示原文对照与改动摘要。
- 每个 unit 保留 `source_text` 与 `source_span`；无法对齐原文时进入异常，不静默丢弃。
- 剧本版本可回退；剧本变化会使对应音频失效。

示例：

```text
原文：
“啪”的一声，惊堂木被县太爷重重拍下。

轻改编：
SFX      惊堂木重拍（啪）
旁白     惊堂木被县太爷重重拍下。
```

### 4.5 自动选角

- “声音库”升级为“配音员库”，配音员是全局资产，不属于某一本书。
- 新书自动选角：
  1. 读取角色圣经与角色阶段；
  2. 按性别呈现、年龄感、音色标签、性格、语言匹配历史配音员；
  3. 有合适候选则复用，并记录匹配置信度；
  4. 没有合适候选则自动生成 1–2 个配音员，并自动绑定；
  5. 同一本书的主要角色避免使用同一配音员；
  6. 旁白单独选角，不与角色混用。
- 一个角色跨幼年/青年/老年可以有多个阶段选角；阶段切换由角色弧与场景状态驱动。
- 配音员可跨书复用；提供使用次数、最近使用、收藏和试听。
- 自动选角不要求逐角色确认；生成失败或候选冲突才进入异常收件箱。

### 4.6 制作方案与异常收件箱

制作方案页只展示三类信息：

1. 本书角色与阶段选角总表；
2. 有声剧本摘要与音效 cue 列表；
3. 异常项（低置信、别名冲突、说话人不明、无可用声音、原文对齐失败、生成失败）。

用户动作：

- “全部接受并生成”：高置信项直接通过，异常项按默认策略处理或跳过；
- “只看异常”：进入收件箱逐项处理；
- 批量接受/批量修改；
- 手动修改任何字段；只有用户编辑过的字段产生锁定。

不再要求“每个角色都必须确认”。审核是例外处理，不是开工前置关卡。

### 4.7 生成与试听

- 0.5.0 先支持选中片段/选中剧本单元的同步生成，复用现有 CosyVoice 链路。
- 音频仍按 `vNNN.wav` 版本化，支持回退；音频二进制不入 SQLite。
- 0.6.0 再接持久化队列、批量生成、暂停/取消/重试、连续播放器和断点恢复。
- 音效/环境音 cue 不进入 TTS，只在剧本和导出标记中保留。

## 5. 功能需求

### 5.1 书库与导入

- **FR-BOOK-101**：新建书籍只能通过 TXT 导入；UI 移除“新建空项目”入口。
- **FR-BOOK-102**：已有空书支持“导入正文到本书”；导入成功后状态变为 ready；也支持删除空书。
- **FR-BOOK-103**：书库卡片显示生产状态（未分析/设定中/待审/可生成/生成中/失败），不再只显示“空项目”。

### 5.2 全书角色圣经

- **FR-BIBLE-001**：生成全书角色表，包含标准姓名、别名、性别、年龄阶段、身份、关系、角色层级、声音描述、证据与置信度。
- **FR-BIBLE-002**：生成人物弧与阶段；每个阶段记录年龄阶段、剧情时间范围、章节范围、性格与声音倾向。
- **FR-BIBLE-003**：记录剧情时间线与叙事模式（顺叙/倒叙/插叙/回忆/梦境）；角色状态按剧情时间解释。
- **FR-BIBLE-004**：别名冲突、身份反转、疑似同一人物进入异常收件箱；不静默合并。

### 5.3 分场与角色状态

- **FR-SCENE-001**：每章拆分为场景，记录地点、时间、视角、气氛、摘要、原文范围。
- **FR-STATE-001**：每个场景的每个出场角色有状态快照，至少包含年龄阶段、身体、心理、关系、知情、伪装和声音提示。
- **FR-STATE-002**：状态带置信度与原文证据；低置信进入异常，不阻塞其他场景。
- **FR-STATE-003**：说话人、情绪、强度、演绎方式继续保留现有字段和置信度规则。

### 5.4 有声剧本

- **FR-SCRIPT-001**：生成独立的有声剧本版本，原文只读；支持版本列表、对照和回退。
- **FR-SCRIPT-002**：默认轻改编；标准/强改编可选；改编档位写入版本元数据。
- **FR-SCRIPT-003**：剧本单元支持旁白、对白、内心、音效、环境、停顿；音效/环境只做 cue。
- **FR-SCRIPT-004**：每个 unit 保留原文与 `source_span`；无法对齐时进入异常，不得静默丢弃。
- **FR-SCRIPT-005**：剧本或表演字段变化时，对应音频标记 stale，旧音频版本保留。

### 5.5 配音员与选角

- **FR-VOICE-101**：全局配音员库，支持标签、试听、收藏、使用记录与跨书复用。
- **FR-VOICE-102**：新书自动选角；优先复用历史配音员，无合适候选时自动生成并绑定。
- **FR-VOICE-103**：一个角色可有多个阶段选角；旁白独立选角；同书主要角色避免撞声。
- **FR-VOICE-104**：自动选角失败、无参考音、生成失败进入异常收件箱；不静默使用其他角色声音。
- **FR-VOICE-105**：现有书内音色迁移为全局配音员，保留来源、引用与旧 WAV。

### 5.6 审核与制作方案

- **FR-REVIEW-001**：异常收件箱按严重级别聚合低置信、冲突、缺失、失败项。
- **FR-REVIEW-002**：制作方案页支持“全部接受并生成”“只看异常”“批量接受/修改”。
- **FR-REVIEW-003**：AI 高置信默认通过；用户编辑才写入锁定字段；重跑不得覆盖锁定字段。
- **FR-REVIEW-004**：不设置逐角色确认关卡；异常项允许带风险继续，但必须可见。

### 5.7 UI 与可访问性

- **FR-UI-001**：正文对比度 ≥4.5:1；弱化文字 ≥3:1 且只用于非关键信息；关键元信息不得小于 12px。
- **FR-UI-002**：提供石墨深色与纸张浅色主题；默认深色，但不再使用纯黑背景。
- **FR-UI-003**：状态不能只靠颜色表达；焦点环、悬浮、禁用态可辨识。
- **FR-UI-004**：建立项目内 `novelvoice-ui` skill，固化颜色、字号、间距、组件与验收清单。

## 6. AI 管线

### 6.1 分遍处理

| 步骤 | 输入 | 输出 | 备注 |
|---|---|---|---|
| P0 章节摘要 | 单章原文 | 章节摘要、事件、人物提及 | 可复用现有摘要 |
| P1 实体抽取 | 章节/窗口 + 已确认角色 | 候选角色、别名、关系、证据 | 可复用现有角色 Prompt，强化全书视角 |
| P2 角色圣经合并 | P1 结果 + 章节摘要 | 全书角色表、人物弧、剧情时间线 | 确定性合并 + LLM 归并 |
| P3 分场分析 | 单章 + 圣经 + 相邻摘要 | 场景、说话人、角色状态 | 按剧情时间解释状态 |
| P4 有声剧本 | 场景 + 状态 + 圣经 | 剧本版本、unit、SFX cue | 默认轻改编 |
| P5 自动选角 | 角色/阶段 + 配音员池 | 选角表、缺失声音任务 | 规则优先，LLM 辅助解释 |
| P6 方案汇总 | 以上结果 | 制作方案、异常收件箱 | 用户只审异常 |

### 6.2 上下文与缓存

- 不允许把整本书一次塞入 LLM。
- 以章节或可控窗口为单位抽取；结果持久化后可复用。
- 角色圣经合并使用 map-reduce：先按章节/卷汇总，再做全局归并。
- Prompt 版本、模型名、耗时、token 统计写入对应版本元数据。
- 重跑某章只失效该章的场景/剧本/音频，不无条件重跑全书。
- 失败必须可见：任务状态、错误码、错误信息、日志位置；不得把超时或空结果记为成功。

### 6.3 模型策略

- 真实模式仍只允许本机 Ollama 回环地址。
- 4B 模型适合单章抽取，不适合一次性全局综合；先用 4B + map-reduce 验证。
- 若全局归并质量不足，提供可配置的更强本机 Ollama 模型用于“角色圣经合并/剧本改编”，不引入云模型。
- 模型选择、下载与体积变化必须写入文档并征得用户同意；不自动下载。
- Mock Provider 必须覆盖新管线，返回确定性数据供测试。

### 6.4 置信度与异常

- 每个角色、别名、关系、状态、说话人、剧本对齐都保存置信度与证据。
- 低于阈值不阻塞生成，但必须进入异常收件箱。
- 以下情况始终进入异常：
  - 别名指向多个角色；
  - 说话人无法可靠判断；
  - 角色状态与剧情时间冲突；
  - 剧本 unit 无法对齐原文；
  - 角色无可用配音员或参考音缺失；
  - 音频生成失败。

## 7. 审核模型

### 7.1 默认自动通过

- 高置信角色、别名、关系、场景状态、剧本单元默认通过。
- 用户不需要逐角色点击“确认合适”。
- 自动通过不等于“事实已人工确认”；UI 要区分“AI 自动接受”和“人工确认”。

### 7.2 异常收件箱

- 只显示需要人判断的项目，按 blocking/warning/info 排序。
- 支持批量接受、批量修改、忽略并记录原因。
- 阻塞项只阻止对应片段生成，不阻止整本书其他部分。

### 7.3 制作方案

- 一次展示角色/阶段选角、剧本摘要、音效 cue、异常数量。
- “全部接受并生成”是主按钮；“只看异常”是次按钮。
- 生成前显示影响范围：多少角色、多少片段、预计缺失声音、需要生成的配音员数量。

### 7.4 锁定

- 只有用户编辑过的字段写入 `user_locked_fields_json`。
- 重跑时保留锁定字段，并在结果中说明被保留的字段。
- AI 自动结果不产生锁定。

## 8. UI 设计

### 8.1 信息架构

| 区域 | 内容 |
|---|---|
| 书库 | 导入 TXT、书籍卡片、生产状态、回收站 |
| 制作台 | 设定集 / 分场分析 / 有声剧本 / 选角 / 生成 |
| 配音员库 | 全局配音员、标签筛选、试听、收藏、使用记录 |
| 任务 | 0.5.0 显示当前同步任务；0.6.0 接入队列 |
| 设置 | 模型、阈值、主题、数据目录、引擎状态 |

### 8.2 视觉 token

深色主题不再使用纯黑：

| Token | 深色建议 | 浅色建议 | 用途 |
|---|---|---|---|
| `bg` | `#0f1115` | `#f6f4ef` | 页面背景 |
| `surface` | `#161a20` | `#ffffff` | 卡片 |
| `surface-raised` | `#1c2128` | `#efece5` | 浮层/输入 |
| `text-primary` | `#e6e9ee` | `#1c2026` | 标题/正文 |
| `text-secondary` | `#b6bec9` | `#4a5360` | 说明 |
| `text-tertiary` | `#8f99a7` | `#6b7482` | 元信息 |
| `text-disabled` | `#5b6470` | `#9aa1aa` | 禁用，仅非关键 |
| `border` | `#2a313a` | `#ddd8ce` | 分割线 |
| `accent` | `#d6a85a` | `#8a6420` | 主操作/强调 |

字号阶梯：12 / 13 / 14 / 15 / 18 / 24 / 32。正文 15px，阅读区 17px；不再用 9px 承载关键信息。

### 8.3 组件规则

- 所有可点击元素有明确 hover/focus/active 状态；焦点环不能被 `outline: none` 清除。
- 状态标签同时提供文字，不只靠颜色。
- 表格/列表的次要信息最小 12px；时间、字数、ID 等可以用等宽字体，但不降低可读性。
- 深色与浅色主题都做对比度检查；至少覆盖正文、次级文字、按钮文字、输入占位、禁用态。
- 中文正文行高不低于 1.7；阅读区最大宽度控制在 68–76 个汉字。

### 8.4 `novelvoice-ui` skill

- 使用 skill-creator 创建项目内 skill，随仓库提交。
- 内容：颜色 token、字号阶梯、间距、圆角、阴影、状态色、Naive UI overrides、深/浅主题规则、中文排版、对比度检查清单、截图评审清单。
- 后续 UI 改动先查 skill，不再在组件里散落十六进制颜色和 9px 字号。

## 11. 0.5.0 验收标准

### 11.1 环境与迁移

- 后端/前端测试通过；迁移 dry-run 与真实迁移均通过。
- 迁移前后书籍、章节、角色、音频资产数量一致；WAV 校验和不变。
- 迁移可重复执行，不产生重复配音员/剧本单元。

### 11.2 全书设定

- 使用至少 3 个角色、别名、倒叙或成长变化明显的测试文本。
- 生成角色圣经、人物弧、剧情时间线；至少 1 个角色有 2 个年龄/状态阶段。
- 不需要逐角色确认即可进入下一步。
- 低置信别名冲突进入异常收件箱。

### 11.3 分场与状态

- 至少一章拆出多个场景；每个场景的出场角色有状态快照。
- 倒叙场景使用对应剧情时间的状态，不沿用当前章节时间。
- 说话人、情绪、证据可见。

### 11.4 有声剧本

- 默认轻改编；原文与剧本可对照。
- 至少 1 条拟声词被拆为 `sfx` cue，且不进入 TTS。
- 剧本版本可回退；修改后旧音频 stale。
- 无法对齐原文的 unit 进入异常，不静默丢弃。

### 11.5 配音员与选角

- 自动选角至少复用 2 个历史配音员、生成 1 个新配音员并自动绑定。
- 旁白与角色声音分离；同一本书主要角色不撞声。
- 跨书复用验证：同一配音员可被第二本书选中。
- 无合适声音时自动生成；失败进入异常。

### 11.6 制作方案与生成

- 制作方案一次展示角色、阶段选角、剧本摘要、异常数量。
- “全部接受并生成”可完成选中片段生成；高置信项不需要逐项确认。
- 生成 4 条以上片段，WAV 可播放；版本 v001/v002 可回退。
- 停止 CosyVoice 后生成明确失败，不伪造成功；重启后恢复。

### 11.7 UI

- 深色与浅色主题正文对比度 ≥4.5:1；关键元信息 ≥12px。
- 页面无 9px 关键文字；状态不只靠颜色。
- 书库无“新建空项目”入口；空书有“导入正文/删除”出口。
- 截图评审通过；`novelvoice-ui` skill 已建立并被使用。

### 11.8 不纳入本次验收

- 实际音效/环境音混音。
- 批量队列、连续播放器、M4B 导出。
- 音质复评与模型许可证签收。

## 12. 风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| 4B 模型全局综合能力不足 | 角色圣经/人物弧质量低 | map-reduce、分卷合并、证据约束、可配置更强本机模型 |
| 长篇分析耗时过长 | 用户等待 | 章节缓存、增量分析、后台任务与进度 |
| 轻改编仍改变原意 | 内容偏差 | 原文对照、改动摘要、source_span 校验、异常收件箱 |
| 自动选角撞声或不适配 | 听感差 | 标签匹配、同书去重、试听、手动覆盖、阶段选角 |
| 迁移破坏旧数据 | 数据丢失 | 自动备份、dry-run、幂等、WAV 不删除、旧表保留 |
| 范围继续膨胀 | 无法交付 | 0.5.0 严格只做剧本 cue、不做混音；队列/导出后移 |
| UI 再次退化 | 可读性问题复发 | `novelvoice-ui` skill、对比度检查、截图评审 |
