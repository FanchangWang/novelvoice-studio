- 日期：2026-11-25

- 目标：在进入阶段 3 的音色库、单段 TTS 和批量流程前，先解决已经暴露的音质问题，避免把缺陷带进阶段 4/5。
- 当前阻塞：用户评分判定跨情绪一致性 1/10、sad 表现力 1/10、尾音气声明显、老年男声拖慢，gate 不通过；RTF 中位数 1.617，未达到 < 1；年轻女性 angry 存在客观音色漂移。需先进入阶段 3B 聚焦修复。

## 1. 已知问题与初步归因

用户试听评分：

| 项目 | 评分 | 遗留问题 |
|---|---:|---|
| 三音色差异 | 8/10 | 基本可用 |
| 跨情绪一致性 | neutral 7 / angry 7 / sad 3 | sad 表现力明显不足 |
| 中文发音与杂音 | 6.5/10 | 句尾存在 `qi` / `si` / `ci` 一类气声 |

初步归因，按优先级排查：

1. **参考音情绪偏差**：三个 VoiceDesign 候选的参考文本都是愤怒台词（“你竟然敢骗我……”），会把紧张感和气息带入音色锚点，尤其不利于 sad。
2. **文本前端缺失**：CosyVoice 日志出现 `no frontend is avaliable`；`ttsfrd` 资源未装配、`wetext` 初始化失败，数字、符号和部分中文规范化未走完整链路。
3. **模型表现力上限**：CosyVoice3 0.5B 对 sad 的控制弱于 angry，需要通过参考音、指令、种子和推理模式组合验证。
4. **推理与拼接**：句尾气声可能来自参考音、随机种子、vocoder 或 chunk 拼接；需要 A/B 隔离，不能只靠后期降噪掩盖。
5. **参考文本条件未生效**：当前 `inference_instruct2` 只消费参考 WAV 的音色提示与自然语言指令，不消费参考文本；需用 `inference_zero_shot` 补测，或明确接受限制。

## 3. 执行顺序

### 3.1 基线与参考音

1. 复听并记录 `candidate_01..03.wav` 与 `neutral/angry/sad.wav`，确认问题是否在参考音本身复现。
2. 用中性、平稳的参考文本重新生成每个角色候选音，参考文本避免强烈情绪和长句。
3. 每个角色至少生成 2–3 个候选，人工挑选最干净的一条；参考音需检查：
   - 句尾是否有气声、爆音、截断；
   - 是否有明显背景噪声；
   - 音色是否符合角色设定；
   - 采样率、声道、峰值是否正常。
4. 对参考音做最小处理：去除首尾静音、短淡入淡出；不要过度降噪或压扁动态。

### 3.2 文本前端

1. 按 CosyVoice 官方路径装配 `ttsfrd` 资源，或修复 `wetext` 初始化。
2. 确认运行日志不再出现 `no frontend is avaliable`。
3. 用固定测试集检查：
   - 中文数字、年份、金额、百分比；
   - 英文缩写、专有名词；
   - 引号、省略号、破折号；
   - 多句连续文本。
4. 若前端仍不可用，记录为明确限制，并改用经过预规范化的文本输入；不能静默忽略。

### 3.3 推理与后处理对比

对同一参考音、同一句文本做以下 A/B：

| 变量 | 对比项 |
|---|---|
| 推理模式 | `inference_instruct2` vs `inference_zero_shot` |
| 随机种子 | 至少 3 个固定种子，观察气声与情绪稳定性 |
| 参考音 | 愤怒参考 vs 中性参考 |
| 拼接 | 单 chunk vs 多句 chunk 拼接，检查接缝与尾音 |
| 后处理 | 原始输出 vs 去首尾静音 + 短淡出 + 响度归一化 |

要求：

- 每次实验记录模型、模式、种子、参考音、文本、指令、输出路径、耗时。
- 句尾气声必须通过波形/试听定位来源，不能用降噪滤镜掩盖后再宣称解决。
- sad 需单独做多轮候选，不拿 angry 的通过结果代替。

### 3.4 评估集

建议建立 20 句固定测试文本，覆盖：

- 旁白 5 句；
- 角色对白 10 句（至少 3 个角色）；
- 内心独白 3 句；
- 数字/英文/标点 2 句。

每个主要角色至少覆盖 neutral / angry / sad 三种情绪；旁白覆盖平静、紧张、悲伤。

执行时保留 20 句中文主集，并额外补充 2 句英文缩写（AI / CEO / KTV / 百分比），实际评估集为 22 句；见 `docs/reports/STAGE3_AUDIO_QUALITY_REPORT.md` 第 7 节。

## 4. 建议的退出标准

以下为阶段 3 内部音质门槛，不是需求书阶段 0 gate 的替代：

- 三音色差异：≥ 7/10（当前 8/10，不得回退）。
- 同一角色跨情绪一致性：neutral / angry / sad 均 ≥ 7/10；其中 sad ≥ 6/10。
- 中文发音与杂音：≥ 8/10；句尾明显气声、爆音、截断在 20 句测试中不超过 2 句。
- 严重缺陷（爆音、重复字、整句截断、明显电流声）：0 例。
- 三个主要角色都能保持稳定音色，不能只验证 `candidate_01`。
- 文本前端：数字、标点、英文缩写测试通过，或已记录可接受的预处理方案。
- 参考文本条件：`inference_zero_shot` 补测通过，或明确记录为阶段 3 已知限制并给出替代方案。
- CUDA 无持续性 OOM；单段生成 RTF < 1（RTX 4070 Ti 目标，非需求硬指标）。

未达到门槛时：

1. 先调整参考音、种子、推理模式和后处理；
2. 仍不达标则评估更大模型或替代 TTS；
3. 不进入阶段 4 批量生成，不把未达标音质带入成片。
