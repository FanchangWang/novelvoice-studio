## 2. 判定说明

1. **跨情绪一致性和 sad 表现力是硬失败。** 两项均为 `1/10`，低于退出标准；不能因为音色差异 `9/10` 或整体可用性 `6/10` 而判为有条件通过。
2. **尾音气声按备注判为缺陷。** 表单中“句尾气声/杂音”填了 `10/10`，与备注“尾音气声太大”矛盾；本记录保留原始分数，但以备注所述的实际听感为准，不把该项目视为已通过。
3. **阶段 3 核心实验使用的参考音与用户最终选择不一致。** 核心 9 条用的是 `narrator_01`、`young_female_01`、`old_male_01`；用户选择的是 `narrator_03`、`young_female_01`、`old_male_03`。因此阶段 3 的客观表和听感结论只能作为筛选依据，不能代表最终候选组合。
4. **老年男性候选本身节奏偏慢。** `old_male_03` 的参考音为 19.14s（清洗后），参考文本约 47 字，约 2.46 字/秒；旁白和年轻女性约 3.8–4.2 字/秒。用户选择的“清瘦克制”仍带有明显拖慢，需要重新设计老年男性参考音。
5. **悲伤表现差与时长异常一致。** 阶段 3 三条 sad 样本都是 10.76s，是 neutral 5.32s 的两倍；当前链路更像“统一放慢 + 长停顿”，而不是自然悲伤。该现象在用户听感中被明确否定。
6. **尾音气声不是单条后处理能证明解决的问题。** 阶段 3 的后处理把尾 200ms 高频占比从 0.1947 降到 0.0041，但用户仍听到气声，说明气声可能位于句内停顿或最后音节释放段，粗糙的尾部裁剪不足以解决。

## 3. 对阶段 3 文档的影响

- `docs/reports/STAGE3_AUDIO_QUALITY_REPORT.md` 的“待听感”状态应改为“听感 gate 未通过”，技术结论保留，不改写阶段 0 的“有条件通过”。
- 阶段 3 应用功能继续冻结。
- 下一轮为 **阶段 3B 聚焦修复**，先解决情感、老年节奏、尾音气声和 RTF，再重新组织试听。

## 4. 阶段 3B 的优先顺序

1. 用用户选择的 `narrator_03` / `young_female_01` / `old_male_03` 重跑核心情绪，确认候选组合的真实表现。
2. 重新设计老年男性参考音，明确“正常语速、不拖腔、句尾干净”，不再使用“缓慢”描述。
3. 固定参考音后，测试更克制的 sad / angry 指令，避免用“悲伤/愤怒”直接触发模型夸张放慢或变声。
4. 用短参考音、prompt 特征缓存和 fp16 测试 RTF，目标回到 `< 1`。
5. 对句尾气声做逐句裁剪、淡出和更严格的尾部阈值对比；必要时限制句内长停顿。
6. 以上通过后再生成小规模盲听页，不直接开发应用页面。
