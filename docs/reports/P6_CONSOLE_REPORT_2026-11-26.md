# P6 制作台 UI 与异常收件箱实施报告

日期：2026-11-26
范围：v0.5.0 AI 生产链重构 P6
状态：已完成，等待 P7 与最终流程评审

## 1. 目标与结论

P6 把 P2–P5 的后端能力接入一个统一的制作台，形成从“导入原文”到“选角就绪”的可操作界面，并把需要人工判断的节点收敛到异常收件箱。

本次完成后：

- 书库卡片与导入结果直接进入 `/books/:bookId/production` 制作台，不再默认进入 0.4.0 书籍工作区。
- 制作台提供「方案 / 设定集 / 分场 / 剧本 / 选角 / 异常」六个页签。
- 声音库改为全局配音员库，配音员不再绑定单本书。
- 全局异常收件箱 `/inbox` 支持跨书筛选、接受、批量接受、填写原因后忽略。
- 书库移除“新建空项目”入口；导入 TXT 是唯一的新书入口（旧空项目数据仍兼容显示）。
- P7 的“选中单元音频生成与试听”尚未接入，制作台会明确显示音频 0/N。

## 2. 后端

新增只读聚合与异常处理 API：

- `GET /api/v1/books/{book_id}/production`：制作概览、派生状态、下一步建议、逐章进度、异常计数与当前任务。
- `GET /api/v1/reviews`：按书籍、状态、级别、编码、实体类型与分页筛选异常。
- `POST /api/v1/reviews/{review_id}/resolve`：单条接受/忽略；忽略必须填写原因。
- `POST /api/v1/reviews/batch-resolve`：批量接受/忽略，幂等处理已关闭项。

关键实现：

- `ProductionService` 汇总设定集、场景、剧本单元、选角、音频资产与开放异常；状态不只看 `Book.production_status`，还由章节与异常派生，避免旧库状态陈旧。
- 开放阻断/警告会使派生状态显示“待处理异常”；仅提示项不阻断，`next_action` 直接推进到音频阶段。
- 接受或忽略以 `cast_` 开头的编码时刷新选角状态，避免选角异常关闭后状态滞后。
- 任务状态映射同时兼容 `chapter_scene` 与 `chapter_scenes`，修正 P5 遗留的任务展示缺口。
- 关闭异常时保留处理人与处理说明；批量接口对已关闭项不重复写入。

## 3. 前端

### 3.1 制作台

- 路由：`/books/:bookId/production`，页签通过 `?tab=` 同步，刷新与分享可回到同一阶段。
- 方案：下一步卡片、当前状态、四个阶段卡片、音频进度、异常摘要、逐章表格；章节行可直接跳到分场或剧本。
- 设定集：章节重跑、任务进度/取消、角色、别名、人物弧、关系与剧情时间线。
- 分场：章节选择、场景与角色状态、原文范围、本章异常与收件箱入口。
- 剧本：章节选择、单元筛选、说话人/情绪/表演提示、cue、版本历史与旧场景版本提示。
- 选角：旁白与角色基础/阶段配音、全局配音员搜索与试听、重新自动选角、缺失角色提示。
- 异常：本书收件箱，支持级别与状态筛选、单条接受、批量接受、忽略原因弹窗。
- 制作台保留“原文与校对”入口，0.4.0 的书籍工作区仍可用于正文校对、拆分合并与旧片段审核。

### 3.2 全局配音员库

- 路由 `/voices` 改为全局配音员库；支持搜索、收藏筛选、已归档筛选、新建、编辑、收藏、归档/恢复、参考音试听与使用统计。
- 编辑只修改配音员资料，不隐式重新生成参考音；界面明确提示此边界。
- 选角弹窗复用同一演员数据，按就绪状态、收藏与关键词筛选。

### 3.3 异常收件箱

- 全局路由 `/inbox`，支持“全部书籍”或单书过滤，点击书名进入对应制作台。
- 接受会保留当前结果并关闭异常；忽略必须填写非空原因。
- 批量操作仅对当前已选且仍处于开放状态的项生效。

### 3.4 书库

- 导入成功后进入制作台。
- 移除“新建空项目”入口及对应弹窗引用；空状态只保留“导入 TXT”。
- 卡片入口文案改为“进入制作台”。

## 4. 验证

自动化：

- 后端：`uv run pytest -q` → **152 passed**（新增 3 个制作台 API 测试）。
- 前端：`npm run build`（`vue-tsc --noEmit && vite build`）通过；`npm test` → **33 passed / 7 files**。

Mock 手动冒烟（本机 127.0.0.1:8765，示例小说 4 章）：

1. 导入 TXT 后进入制作台，方案页显示下一步“生成全书设定集”。
2. 生成设定集 → 4 章分场 → 4 章剧本 → 自动选角，各页签可以读取对应结果。
3. 方案页显示 3 角色、11 场景、45 个剧本单元、4 个配音绑定；音频进度为 0/45，符合 P7 尚未实施的预期。
4. 异常页显示 11 条提示与 1 条警告；接受警告后，派生状态从“待处理异常”变为“可以生成音频”，下一步变为音频。
5. 全局收件箱、全局配音员库、书库入口与页签路由均可无刷新切换。

## 5. 明确限制

- P7 尚未实施：制作台不能为选中的剧本单元生成音频，也没有单元音频版本与连续试听。
- 真实 Ollama 的 P4 剧本质量与 P5 真实声线选角效果未在本阶段重新验收；本阶段 UI 冒烟使用 Mock Provider。
- P6 只新增展示与异常处理，不新增数据库迁移；数据库 head 仍为 `a4c1e8d29b73`。
- 0.4.0 的 `/books/:bookId` 书籍工作区保留用于原文校对与旧链路，不作为新书的默认入口。
- 阶段 0 听感 gate 仍按原结论记录为有条件通过；音质与许可证核对状态不因 P6 改变。
