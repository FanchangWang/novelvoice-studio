- 版本：0.3.0

- 范围：AI 小说分析与审核（本机 Ollama）
- 结论：**自动化测试与真实模型主流程通过**；阶段 0 人工听感 gate 已于 2026-11-25 有条件通过，音质遗留转入阶段 3；阶段 3 真实 TTS / 导出未实现。

## 1. 交付内容

### 1.1 后端

- Ollama Provider：`/api/chat`、`format=json`、`think=false`、回环地址校验、`trust_env=False`。
- Prompt 与 JSON Schema：角色、片段、章节摘要、修复重试，版本号 `stage2.v1.*`。
- 分析管道：角色提取与别名合并、章节摘要、逐段说话人/情绪/演绎分析、保底片段回填。
- 全书任务：`GenerationJob` 进度、取消、失败、启动时中断恢复；单书并发互斥。
- 审核与编辑：片段逐条/批量修改、字段锁定、角色资料编辑/锁定/合并/拆分、别名候选确认、关系维护。
- 重跑语义：锁定字段不被覆盖；未锁定角色允许高置信度新章节刷新资料；同类型正反关系合并。
- 数据迁移：阶段 2 新增表/字段的 Alembic 迁移与旧库升级验证。

### 1.2 前端

- 工作区分栏：原文 / 片段审核 / 角色关系；宽屏右侧分析栏，窄屏「AI 分析」抽屉。
- 分析任务：本章、未完成章节、全书；进度、取消、统计与错误展示。
- 片段审核：状态与置信度筛选、逐条编辑、批量修改、锁定字段提示。
- 角色审核：资料编辑与锁定、别名候选接受、角色合并与拆分、关系列表。
- Mock/真实模式提示；低置信度与回退片段显著标记。

## 5. 已知限制

- 4B 本地模型存在输出波动：同一本书两次运行的片段数、置信度和复核数量可能不同；置信度可能偏高，复核数量不能作为质量指标。
- 真实运行曾出现标点级回退片段与少量对齐失败；系统保留原文并提示复核，未静默丢失。
- 正反关系去重对本次升级前已存在的重复行不追溯清理；新分析不再产生同类型正反重复。
- 角色别名与资料仍可能出现误判，需要人工审核；角色锁定后可避免被重跑覆盖。
- 分析耗时与模型、显卡、章节长度相关；超长章节需先拆分。

## 6. 边界与后续

- 服务仍只监听回环地址；真实 LLM 不允许非本机地址，不调用云 API、不自动下载模型、无遥测。
- 原始小说文本只读保留；编辑仅影响 `speech_text` 等派生字段。
- 阶段 0 的 3 个候选音色与 3 个情绪样本人工试听 gate 已**有条件通过**：音色差异 8/10、跨情绪 7/7/3、发音与杂音 6.5/10；sad 表现力与句尾气声转入阶段 3，不能据此宣称音质验收通过或阶段 0 全部签收。
- 阶段 3 待办：Qwen3-TTS / CosyVoice Worker、音色档案、任务队列执行、音频资产与导出。
