# 阶段 3 应用验收报告

日期：2026-11-26
版本：0.4.0
范围：固定音色库、单段语音生成、音频版本回退与本机 Worker 接入

## 1. 结论

阶段 3 的**应用功能链路已交付并通过功能验收**：

- 旁白与角色可以各自生成多个音色候选，试听后绑定一个固定音色。
- 已绑定音色的片段可以单独生成 WAV、重复生成、试听历史版本并回退。
- Mock 模式可以完整走通上述流程；真实模式已用本机 Qwen3-TTS VoiceDesign 与 CosyVoice3 Worker 完成设计、绑定和单段合成冒烟。
- 本报告只确认“功能可用”，不把阶段 3B/3C 的试听结论扩大为音质验收，也不代表阶段 0 许可证核对完成。

尚未交付（阶段 4）：批量生成、任务队列、连续播放器、章节/全书 M4B 导出、工程混音。

## 2. 交付内容

### 2.1 声音库

- 每本书独立维护旁白与角色音色；角色音色挂在有效角色上，合并角色不会继续出现在声音库。
- 一次设计生成 1–5 个候选，保存参考 WAV、seed、模型、生成参数、采样率、时长与校验和。
- 候选可试听、绑定、切换、删除；当前绑定候选不可删除，已被片段使用或仍为绑定项的候选会返回冲突错误。
- 绑定真实候选时执行参考音去齿（4–10kHz 动态衰减，阶段 3C 定稿参数），记录原始路径、去齿统计与 `reference_processed`；Mock 候选跳过 DSP。
- 删除书籍后不能再读取其声音库；音色音频接口只接受受控 ID，不暴露任意文件路径。

### 2.2 配音工作台

- 书籍工作区新增「配音」页签，列出章节片段、说话人、当前绑定音色与生成状态。
- 只有“已识别说话人 + 已绑定音色”的片段可以生成；未识别/未绑定会明确提示并跳转声音库。
- 生成成功写入 `audio/<chapter>/<segment>/vNNN.wav`，创建 `audio_assets` 记录，并把片段指向最新版本。
- 每次重新生成递增版本号，不覆盖旧 WAV；版本弹窗可试听任意历史版本并切换当前版本。
- 回退版本会同时恢复该版本使用的 `voice_profile_id`，避免“音频是 A 音色、界面显示 B 音色”。
- 修改台词、说话人、情绪、强度、演绎建议等影响音频的字段后，旧音频会失效并要求重新生成；用户锁定字段仍遵循阶段 2 语义。

### 2.3 Provider 与 Worker

- `QwenVoiceDesignProvider`：调用 Qwen Worker 生成候选；真实模式返回 WAV 与 seed/时长元数据。
- `QwenCosyVoiceTTSProvider`：Qwen 按角色描述 + 情绪指令生成情感源，再经 CosyVoice `inference_vc` 转换到固定参考音。
- 单 GPU 下整条 Qwen + CosyVoice 链路由进程内锁串行化，避免两个片段同时抢显存。
- Worker 契约：输入 Base64 JSON 音频/文本，输出音频字节；元数据放 `X-NVS-*` 响应头；只监听回环地址，不接受任意本地路径，不自动下载模型。
- `scripts/start_workers.ps1` / `stop_workers.ps1` 管理两个独立 venv 进程；PID 记录在 `.run/workers`，停止前校验命令行，端口占用但无记录时只报告，不误杀未知进程。

### 2.4 API

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/v1/books/{book_id}/voices` | 读取本书声音库 |
| POST | `/api/v1/books/{book_id}/voices/design` | 生成音色候选 |
| GET | `/api/v1/voices/{voice_id}/audio` | 试听候选参考音 |
| POST | `/api/v1/voices/{voice_id}/select` | 绑定候选（执行参考去齿） |
| PATCH | `/api/v1/voices/{voice_id}` | 修改候选名称/描述 |
| DELETE | `/api/v1/voices/{voice_id}` | 删除未使用候选 |
| POST | `/api/v1/voices/{voice_id}/preview` | 按文本/情绪试听已绑定音色 |
| POST | `/api/v1/segments/{segment_id}/generate` | 为单段生成 WAV |
| GET | `/api/v1/segments/{segment_id}/audio-versions` | 列出音频版本 |
| GET | `/api/v1/segments/{segment_id}/audio` | 播放当前音频 |
| GET | `/api/v1/audio-assets/{asset_id}/audio` | 播放指定历史版本 |
| POST | `/api/v1/audio-assets/{asset_id}/restore` | 回退到指定版本 |

### 2.5 数据与兼容性

- 沿用初始 schema 已有的 `voice_profiles`、`audio_assets` 与片段音频字段，**阶段 3 没有新增数据库迁移**。
- 音频二进制只落文件系统；SQLite 保存相对路径、版本、校验和、Provider/模型与生成参数。
- 路径统一经 `resolve_relative` 校验在数据目录内，写入使用临时文件 + `os.replace` 原子替换。
- 生成结果先校验 RIFF/WAVE、采样率、声道与时长，再落库；非法音频不会成为当前版本。

## 3. 验收证据

### 3.1 Mock 浏览器走查

测试书章节「第一章 雨夜来客」分析得到 11 个片段、4 个 Mock 角色。

- 旁白生成 2 个候选并绑定候选 01。
- 沈砚、见秋没有各生成 2 个候选并绑定候选 01；声音库显示 3/5 个 owner 已绑定。
- 配音页签正确显示 11 个片段，并对未识别说话人/未绑定音色给出阻止提示。
- 旁白片段生成 v001，重新生成得到 v002；版本弹窗同时列出两版，回退 v001 成功。
- 将片段「你姐姐……阿棠还好吗？」的说话人改绑为沈砚后，生成成功，界面显示对应候选与片段音频。
- 抽查音频接口返回 HTTP 200、`audio/wav`，文件头为 `RIFF/WAVE`；大小分别为 17,964 与 38,124 字节。

### 3.2 真实 Worker 冒烟

环境：本机 RTX 4070 Ti，两个 Worker 均通过 127.0.0.1 回环地址启动。

- 健康检查：两个 Worker `ok=true`，CUDA 可用，模型目录存在；模型按需加载。
- 真实设计：Qwen VoiceDesign 生成候选 `voice_35b183c85afe4d4f`，seed 42，耗时约 11.84 秒，采样率 24,000 Hz。
- 绑定：约 0.156 秒完成（仅 DSP）；`reference_processed=true`；去齿统计为 1111 帧中衰减 270 帧，平均约 -2.1 dB，最大 -5 dB。
- 真实合成：单段耗时约 31.9 秒，得到 `asset_e41acc43837e4e85`（version 3），Provider 为 `qwen3_tts+cosyvoice3`，时长 2,480 ms。
- `ffprobe` 确认输出为 PCM s16le、24 kHz、单声道，119,084 字节。
- 停止 Worker 后 8765/8766/8767 端口均关闭。

真实 Ollama 全书分析未在本轮重新验收，阶段 2 的结论仍以 `docs/reports/STAGE2_REPORT.md` 为准。

## 4. 音质结论与遗留

阶段 3 应用验收沿用阶段 3B/3C 的人工试听结论：

- 3B gate 通过：跨情绪 9、sad 8、句尾气声 6、老年男性语速 8、中文发音 8、变声痕迹 8、三音色差异 9、整体可用性 8。
- 3C 定稿：`narrator_03` 参考音先去齿、输出不处理；中性/悲伤首选均为 `refdeess + raw`。
- 剩余问题：用户明确指出“菜 / 三”等字可能读成“ci”；问题集中在 c/s 擦音与韵母起始，不是普通句尾静音。最后一轮 7 条修正未带来明显改善，按用户决定收尾。
- 未做：输出端去齿、擦音时长限制、长期连续收听的疲劳度评估。

因此当前口径是：**真实链路可用，音质“可用但有已知毛刺”**，不能宣称“音质验收通过”或“完整有声书已交付”。

## 5. 未完成项与边界

- 批量生成、任务队列、连续播放、M4B/章节导出仍是阶段 4 范围；任务队列页面仍是占位。
- Worker 环境与模型不会自动安装/下载；首次真实使用需用户显式准备约 14 GB 模型缓存。
- 同一 GPU 上生成是串行的；单段长文本耗时可达数十秒，未做流式或并发优化。
- Mock 声音库与片段只用于联调，不代表真实分析或音色质量。
- 阶段 0 听感 gate 仍为“有条件通过”；sad 表现力、句尾气声与参考文本条件仍是质量待办。
- **许可证核对未完成**：CosyVoice 依赖中的 `ttsfrd`、`wetext` 等仍需单独核对分发与商用条件；本报告不构成许可证结论。
